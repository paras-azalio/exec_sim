===============================================================================
 RESPONSE FILE FORMATS
===============================================================================

A) FLAT TEXT   answers.txt        <command regex> => <reply | @file> | options
-------------------------------------------------------------------------------
date \+%Y-%m-%d_%H-%M-%S                          => 2026-08-11_21-30-00   | profile=sbc
netconfprov .*--user root                         =>                       | profile=sbc, exit=1
netconfprov .*--user netconfcli                   =>                       | profile=sbc, exit=0
cat /storage/CapacityLicenseKey_.*_Precheck\.xml  => @answers/CapacityLicenseKey.xml | profile=sbc

  @file        reply body read from that file (relative to the .txt)
  options      exit=N , profile=sbc|repo|node1|node2|any , occurrences=1,2
  #            comment line
  first rule that matches the command wins


B) SINGLE YAML   answers.yaml     request and response together
-------------------------------------------------------------------------------
profile: sbc
users:
  sbcadmin: sbc
  installer: repo
exchanges:
  - request:  'date \+%Y-%m-%d_%H-%M-%S'
    response: '2026-08-11_21-30-00'

  - request:  'netconfprov .*--user root'
    response: ''
    exit: 1

  - request:       'cat /storage/CapacityLicenseKey_.*_Precheck\.xml'
    response_file: answers/CapacityLicenseKey.xml

  request        regex matched against the command
  response       inline reply   (response_file: path for a big/multi-line body)
  exit           process exit code, default 0
  occurrences    [1,3] -> only the 1st and 3rd time this command is seen
